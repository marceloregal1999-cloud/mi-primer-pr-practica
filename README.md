# Mi Primer PR - Práctica

Este repositorio es un espacio de práctica para aprender el flujo de trabajo de Git y GitHub.

## ¿Qué es un Pull Request?

Un Pull Request (PR) es una forma de proponer cambios a un repositorio. Permite que otras
personas revisen tu codigo antes de que se combine con la rama principal.

## Pasos básicos

1. Crea una rama nueva.
2. Haz tus cambios y confirma (commit).
3. Sube la rama al repositorio remoto (push).
4. Abre un Pull Request para que se revise y se combine.
